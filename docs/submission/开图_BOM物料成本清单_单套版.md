## 一、填写说明

### 1.1 单套核算范围

**本清单只核算 1 套开图比赛原型。** 包括 1 台借用相机、1 台已有电脑、1 台已有手机、实际需要的采集配件，以及 1 个已有服务器上的项目部署。

不加入批量生产预算，不为每位网页访问者配置相机。设备借用、自有资产和实际新增采购分开列示；团队工时与已支付人工费用分开记录。

### 1.2 金额规则

- **0 元新增采购**：本方案不新增购买该项，不代表设备没有价值。
- **待确认**：尚未取得费用或凭证，不能当作 0 元，也不能虚构数字。
- **可选费用**：只有实际启用或采购时才计入，不预先加入比赛必需成本。
- **研发工时**：与采购现金支出分开；团队投入不等于没有经济成本。
- 本文件沿用主办方模板的五章结构，按软件原型实际形态调整物料项目。
