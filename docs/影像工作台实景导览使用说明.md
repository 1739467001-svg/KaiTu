# 开图影像工作台：从影石素材到可分享导览

## 四步得到结果

1. **导入实景**：使用 Studio 导出的 2:1 全景 JPG、PNG、WebP，或已拼接 H.264 MP4。照片浏览副本最长边为 4096 像素；视频建议单点 10–20 秒、单文件不超过 80 MB。保留原片。最多 12 个点位。
2. **标注连接**：打开定位热点，拖动画面，把入口或通道对准中心十字，再选择目标点位并保存。需要返回时另外设置返回热点。入口必须能沿热点到达所有点位，才能发布。
3. **完善信息**：将餐饮点标记为餐厅，填写确认过的入口、餐品及营业信息。文字整理助手是基于已输入内容的本地模板，不是视觉 AI，不生成未经确认的价格。
4. **预览发布**：先用游客视角检查，再输入后台密钥、确认公开范围，发布生成独立链接和二维码。可更新同一链接，也可撤回。未被该导览引用的后台素材不会通过导览开放。

## 拍摄点位动态提醒

大门、通道、签到处、餐厅入口提供高亮当前点、完成标记、下一点提醒及对应拍摄提示。全景中的热点有呼吸高亮。此功能是人工采集计划，不会读取相机 GPS、不自动识别机位、不远程驱动相机。

## 示例与实拍

“先体验”提供四点位插画示例及六个跳转热点，明确标注非现场实拍。不要将其用于现场导航。先移除示例点位，再导入自己的实拍；不会将比赛照片自动导入或自动重建模型。

## 保存和公开范围

草稿及媒体浏览副本保存在本机浏览器 IndexedDB；换浏览器或清理数据不会自动恢复这些草稿。密钥只在页面内存中。发布后服务器保存导览及所选浏览副本；持链接的游客无需密钥访问。撤回后公共接口不可再读，但不能收回别人此前下载的副本。现阶段是单份本机草稿工作流，不是多账号作品管理系统。
